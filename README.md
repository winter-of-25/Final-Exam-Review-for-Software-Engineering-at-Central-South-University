# 中南大学软件工程专业期末复习资料

## 简介

这是我在期末复习时整理和使用的一些资料，希望能帮助到后续学习软件工程专业相关课程的学弟学妹。

至于为什么创建这个仓库呢，是感觉大学这些课程千人千面，不同老师考核的内容天差地别，有人把经验写下来的话会帮助大家更快更好的复习，而不是让这些信息沦为信息差，或者说，知识平权。

本人绩点比较一般，平时也有点懒，所以这里的资料主要适合**期末速成、临时抱佛脚、刷题复习**使用。如果你对绩点有较高追求，建议平时多花时间系统学习课程内容，不要只依赖这些资料。

## 资料说明

本仓库主要整理了一些我制作的用于期末复习的佛教刷题题库 ID和复习速成资料，方便大家快速查找和刷题。

每门课程的文件夹种都会有**说明**,请一定要先看说明再进行复习，其中写了我当时复习这门课的感受以及考试的相关信息。

注：直接在微信搜索佛脚刷题就能看到小程序
